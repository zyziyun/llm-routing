# LLM Router 这一讲

基于本 repo 和 docs/EXPERIMENTS.md 的七个真实验,做的一整讲教学材料。

- [handout.md](handout.md) 学生讲义,极简风,含所有真数据结论。发给学员。
- [script.md](script.md) 你的讲稿加大纲,60 分钟节奏,含口播要点和 aha 时机。上课对着讲。
- [demo.md](demo.md) 现场演示脚本,离线可跑的现场跑,重实验展示已提交的图和数。

主线:router 和自建 GPU 都不是自动更便宜,便宜又强的开源托管模型在侵蚀二者,值不值取决于档位成本差。这条是这一讲和别处不一样的地方。
